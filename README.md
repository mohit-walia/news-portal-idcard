# News Portal ID Card

## Setup Instructions

### Prerequisites
- Node.js (version 14.x or later)
- npm (Node Package Manager)

### Installation Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/mohit-walia/news-portal-idcard.git
   cd news-portal-idcard
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file in the root of the project and set up your environment variables. Here's a sample:
   ```env
   DATABASE_URL='your_database_url'
   API_KEY='your_api_key'
   ```

4. Run the application:
   ```bash
   npm start
   ```

### Usage
- Access the application at `http://localhost:3000`

### Features
- Feature 1: User Authentication
- Feature 2: News Display
- Feature 3: User Profile Management
